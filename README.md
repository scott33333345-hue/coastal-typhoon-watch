# 沿海台风实况与预警平台

面向中国沿海居民的台风信息网站。项目目标是在手机上用最短时间回答四个问题：

1. 台风叫什么？
2. 现在在哪里？
3. 正往哪里走？
4. 风力有多大、我所在地区是否需要采取行动？

当前阶段已完成产品规划和实时数据展示页面，详细规划见 [PLAN.md](./PLAN.md)，网页源码位于 [`dist/`](./dist)。

> 安全声明：本项目只转述权威部门发布的实况、预报和预警，不自行发布气象预警。发生灾害时，请以当地气象台、应急管理部门和政府通知为准。

## 本地预览

直接打开 `dist/index.html`，或在项目根目录启动任意静态文件服务器并访问 `dist/`。

页面包含：

- 台风名称、位置、移动方向、速度、风力和气压数据面板
- 支持 24/48/72 小时切换的 SVG 路径示意图
- 黄色预警详情、居民行动建议及四色预警等级
- 桌面端和移动端响应式布局
- 数据来源、观测时间、抓取时间和延迟状态提示

## 数据更新

`scripts/fetch-typhoon.mjs` 从浙江省水利厅台风路径实时发布系统读取年度台风列表和台风详情，将标准化结果写入 `dist/data/typhoon.json`。GitHub Actions 每 15 分钟运行一次；上游数据没有变化时不会产生空提交。

> 本站只是对公开数据的自动转述，不自行发布气象预报或预警。数据可能延迟或中断，请始终以当地气象台、应急管理部门和政府通知为准。
