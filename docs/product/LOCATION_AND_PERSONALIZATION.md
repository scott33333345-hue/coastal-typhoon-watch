# 海风哨位置与个性化影响设计

确认日期：2026-10-18  
状态：已确认

## 设计原则

采用“手动选择城市优先，浏览器定位作为可选增强”的方案。首版完整验证福建·厦门，架构支持后续扩展更多沿海城市。

个性化模块只输出可以由真实坐标和来源数据验证的空间关系，不自行生成官方预警、登陆判断或属地风险等级。

## 1. 位置使用层级

### 未选择城市

首次访问不自动申请定位权限。页面提示用户选择关注城市，同时允许继续查看全国台风实况与路径。

### 手动选择城市

- 首版提供福建·厦门；
- 显示“当前关注：福建·厦门”；
- 在当前设备保存所选城市；
- 支持更换和清除；
- 未完成真实能力的城市不进入可选列表。

### 使用当前位置

用户主动点击后才请求浏览器定位权限：

- 授权成功后临时使用坐标计算距离；
- 拒绝授权后继续提供手动选城；
- 定位失败时解释状态并提供选城入口；
- 不强制定位；
- 不在服务器长期保存精确坐标。

## 2. 位置来源与精度表达

| 位置来源 | 页面文案 |
| --- | --- |
| 手动选择城市 | 根据厦门城市参考点估算 |
| 浏览器精确定位 | 根据本次设备位置估算 |
| 浏览器粗略定位 | 根据设备提供的大致位置估算 |
| 未选择位置 | 尚未计算本地关联 |
| 定位失败 | 无法获取位置，请手动选择城市 |

使用城市参考点时统一描述为“距离厦门城市参考点”，不得写成“距离你”。

## 3. 可验证的空间计算

### 当前距离

使用用户位置或城市参考点与最新台风中心坐标，通过 Haversine 公式计算球面距离。

显示整数公里并使用“约”，避免虚假的精确感。计算必须验证经纬度范围和数据时间。

### 相对方位

计算台风中心相对关注地点的初始方位角，再转换为用户可理解的方向，例如“东南方向”。

### 接近或远离趋势

比较至少两个有效实况点到关注地点的距离：

- 正在接近；
- 正在远离；
- 距离变化不明显；
- 数据不足，暂无法判断。

展示所使用的实况时间范围。单点、时间倒序、跨度不足或坐标异常时不输出趋势。

### 预测路径最近点

仅在同一预测机构的有效预测点中寻找距离城市最近的离散点，展示距离、预测时间和机构。

必须同时说明：

> 这是离散预测点与城市参考点的距离，不代表登陆地点或实际影响时间。

## 4. 暂不输出的结论

没有额外权威气象和属地数据支持时，不输出：

- 预计登陆厦门的时间或地点；
- 厦门一定不会受到影响；
- 台风将在多少小时后到达用户位置；
- 用户所在地的具体风力或降雨量预测；
- 停工、停课或撤离判断；
- 本站生成的蓝、黄、橙、红风险等级。

## 5. 本地影响卡片

建议内容顺序：

1. 当前关注城市和位置来源；
2. 台风相对城市的方向；
3. 当前距离；
4. 一段时间内的接近或远离趋势；
5. 预测路径最近点和时间；
6. 本站计算标识；
7. 预测机构和数据时间；
8. 本地官方预警数据状态；
9. 一般性行动建议。

每个计算结果都应提供“如何计算”说明入口。

## 6. 个性化模块状态

- 尚未选择城市；
- 正在获取位置；
- 正在计算；
- 计算完成；
- 数据不足；
- 数据已经过期；
- 坐标无效；
- 定位权限被拒绝；
- 定位服务不可用。

风险判定规则尚未经过验证前，不根据距离自动输出低、中、高风险。首版使用“距离较远，持续关注路径变化”等描述性文案，并明确它不是官方结论。

## 7. 多台风排序

同时存在多个活动台风时，按以下信息确定默认展示顺序：

1. 是否存在与所选地区对应的生效官方预警；
2. 预测路径最近点与城市的距离；
3. 当前距离和接近趋势；
4. 数据新鲜度。

推荐文案：

> 根据当前公开数据，优先展示与厦门空间关系最近的台风。

在没有权威风险信息支持时，不使用“最危险台风”。

## 8. 隐私规则

- 首次打开页面不自动请求定位；
- 请求前解释定位用途；
- 精确坐标默认只在当前设备参与计算；
- 默认只持久保存用户选择的城市标识；
- 提供清除城市和定位状态的入口；
- 分析事件不记录精确经纬度；
- 分享链接不包含精确位置；
- 拒绝或关闭定位不影响基础功能。

定位授权前推荐文案：

> 用于计算台风与你的大致距离。位置只在当前设备处理，不会公开或写入分享链接。

## 9. 首版范围

### 首版实现

- 厦门城市参考点及来源说明；
- 手动选择并在当前设备保存厦门；
- 当前距离；
- 相对方位；
- 接近或远离趋势；
- 预测路径最近点；
- 数据不足、坐标异常和定位失败状态；
- 计算方法说明。

### 后续扩展

- 更多沿海城市；
- 浏览器定位；
- 区县级官方预警；
- 用户关注城市列表；
- 多城市影响对比。

## 验收标准

- 不授权定位也能完整使用基础功能；
- 首次访问不自动请求定位；
- 手动选择的城市可在下次访问时恢复；
- 城市参考点与设备位置具有不同精度说明；
- 距离、方向和趋势由真实坐标计算；
- 计算结果展示数据时间、来源和计算依据；
- 预测最近点不被描述为登陆点或影响时间；
- 数据过期或坐标异常时不输出确定性结论；
- 不保存、上报或分享精确经纬度；
- 390px 移动端可以完成选城和查看个性化信息。
