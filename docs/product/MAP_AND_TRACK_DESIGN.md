# 海风哨地图与路径设计

确认日期：2026-10-18  
状态：已确认

## 设计目标

新版地图集中回答四个问题：

1. 台风现在在哪里；
2. 台风之前经过哪里；
3. 官方预计台风往哪里移动；
4. 台风与用户关注城市有什么空间关系。

地图只用于解释实况和预测，不自行发布预警，也不把预测路线表现为确定路线。

## 模块结构

路径模块采用以下顺序：

> 路径结论 → 真实地理地图 → 时间控制 → 文字时间线 → 数据说明

## 1. 路径结论

地图上方使用简短文字总结：

- 台风当前位置相对关注城市的方位；
- 当前移动方向和速度；
- 官方预测路径的总体方向；
- 数据时间和预测机构。

距离和接近趋势未完成真实计算时，明确显示“暂未完成与厦门的距离及接近趋势计算”，不得使用模拟数字。

## 2. 地理底图

使用基于真实经纬度的地图替换现有手绘示意底图，至少展示：

- 海岸线与必要的省市地理参照；
- 福建·厦门城市标记；
- 当前台风中心；
- 历史实况路径；
- 官方预测路径；
- 缩放比例和底图来源。

地图实现不得依赖固定像素宽度。底图服务不可用时，路径数据与文字时间线仍须可读。

## 3. 路径视觉规则

| 信息类型 | 视觉规则 |
| --- | --- |
| 历史实况路径 | 深青色实线 |
| 历史实况点 | 小型实心圆点 |
| 当前台风中心 | 高对比标记和静态光环 |
| 官方预测路径 | 橙黄色虚线 |
| 官方预测点 | 空心圆点 |
| 关注城市 | 蓝色城市标记 |
| 城市与台风距离 | 用户选择后显示辅助连线 |
| 七、十、十二级风圈 | 默认关闭，允许按等级切换 |

实况和预测必须同时通过颜色、线型、点型和文字区分，不得只使用颜色编码。

## 4. 预测不确定性

当前数据没有提供概率锥、集合预报离散范围或其他可验证的不确定性范围。因此：

- 删除现有“不确定性范围”图例；
- 不绘制虚构的预测锥；
- 显示“预测路径会随新数据调整”；
- 显示预测机构；
- 不使用“将到达”等确定性语言描述预测点。

只有接入真实且来源清晰的不确定性数据后，才允许增加概率范围。

## 5. 时间控制

- 保留未来 24、48、72 小时切换；
- 默认展示未来 72 小时；
- 时间切换只过滤预测点，不隐藏当前实况点；
- 显示当前范围对应的截止时间；
- 地图只标记关键时间，避免文字重叠；
- 点选路径节点后显示时间、类型、强度、风速、气压和坐标。

## 6. 城市关联

地图展示福建·厦门标记。完成真实坐标计算后，可以展示：

- 台风中心与厦门的球面距离；
- 台风中心相对厦门的方位；
- 一段时间内正在接近还是远离；
- 预测路径中与厦门距离最近的点及对应时间。

以上结论必须标注为“本站根据公开坐标计算”，并与官方预报、官方预警分区展示。

距离建议采用 Haversine 公式计算。接近趋势至少比较两个有效实况点到目标城市的距离，并显示计算采用的数据时间范围。单个点或坐标异常时不输出趋势。

## 7. 移动端规则

- 地图宽度自适应视口，不允许依赖横向滚动；
- 默认高度约 360–420px；
- 支持触控缩放与拖动；
- 时间切换位于地图下方；
- 图例保持两到三项主要内容，其余进入说明；
- 节点详情使用不遮挡地图主要区域的信息卡；
- 提供“查看文字路径”入口；
- 所有地图外控制按钮的触控区域不小于 44 × 44px。

地图手势不得阻断页面的正常纵向滚动。

## 8. 文字时间线

地图下方提供等价的结构化时间线，每个节点包含：

- 日期和时间；
- 实况或预测标识；
- 预测机构；
- 台风强度；
- 经纬度；
- 风速和气压；
- 数据缺失提示。

文字时间线服务于移动阅读、键盘操作、辅助技术和地图加载失败场景，不是地图的附属装饰。

## 9. 页面状态

| 状态 | 处理方式 |
| --- | --- |
| 地图与路径正常 | 展示地图、控制和文字时间线 |
| 底图加载失败 | 保留路径摘要、文字时间线和来源链接 |
| 路径数据延迟 | 显示最后成功时间和延迟提示，降低结论确定性 |
| 无预测路径 | 只显示实况路径，明确说明来源暂未提供预测 |
| 无活动台风 | 显示无活动台风状态，可查看最近历史路径 |
| 多个活动台风 | 默认选择与关注城市最相关者，并提供切换 |
| 坐标异常 | 忽略异常点、记录状态并避免输出错误距离 |

## 10. 数据和安全边界

- 每条预测路径必须带预测机构信息；
- 路径更新时间与页面抓取时间分别展示；
- 地图底图和路径数据来源分别标注；
- 不使用地图路径自动生成行政区域官方预警；
- 不将距离、方位或接近趋势包装成官方结论；
- 地图不能作为航海、撤离路线或其他专业导航依据。

## 验收标准

- 页面不存在演示或虚构路径文案；
- 所有路径节点使用真实数据坐标；
- 实况和预测无需依赖颜色即可区分；
- 不展示来源数据未提供的不确定性范围；
- 地图明确展示预测机构、数据时间和来源；
- 390px 视口不存在地图引起的横向滚动；
- 地图与文字时间线提供相同的核心路径信息；
- 厦门距离和趋势只在真实计算成功后展示；
- 底图加载失败时仍可获取当前状态和预测时间线；
- 交互控件支持键盘操作并具有明确名称和焦点状态。
