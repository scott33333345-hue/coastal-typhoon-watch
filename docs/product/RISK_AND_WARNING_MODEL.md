# 海风哨风险与预警信息模型

确认日期：2026-10-18  
状态：已确认

## 设计目标

将数据运行状态、台风强度、本地影响判断和属地官方预警彻底拆分，避免把来源系统字段、台风强度或本站计算结果包装成官方预警。

## 规范依据

- 中国气象局《气象灾害预警信号发布与传播管理办法》：https://www.cma.gov.cn/zfxxgk/gknr/flfgbz/gz/202005/P020220628619411458474.pdf
- 福建省人民政府《福建省气象灾害预警信号发布与传播办法》：https://www.fujian.gov.cn/zwgk/zfxxgk/szfwj/jgzz/xzgfxwj/202212/t20221223_6083363.htm

气象灾害预警信号只转述有权限的属地气象台站所发布的信息。本站不根据风力、距离或路径预测自行生成官方预警。

## 四层信息模型

### 第一层：数据运行状态

回答“网站数据是否及时、完整、可信”。

状态包括：

- 数据正常；
- 数据可能延迟；
- 数据严重滞后；
- 数据加载失败；
- 部分来源不可用。

该层只描述网站和数据链路，不使用“台风预警”名称。

### 第二层：台风强度

回答“台风中心当前有多强”。

可展示来源提供的强度名称、最大风力、风速和中心气压。必须明确说明台风中心强度不等于用户所在地的官方预警，也不直接代表当地影响程度。

该层不使用属地预警卡片的颜色、图标或标题结构。

### 第三层：本地影响判断

回答“根据关注城市和公开路径数据，台风与本地有什么关系”。

| 状态 | 使用条件 |
| --- | --- |
| 暂无法判断 | 数据不足、过期、计算失败或缺少必要来源 |
| 暂未明显影响 | 当前路径、距离和时间窗口未显示近期明显影响 |
| 建议持续关注 | 台风正在接近，或预测路径可能靠近 |
| 可能产生影响 | 有效预测和时间窗口支持存在影响可能 |
| 正在产生影响 | 有可验证实况或官方信息支持当前影响 |

该层必须标注“本站根据公开坐标和路径数据辅助计算，不是官方预警”。不得使用蓝、黄、橙、红作为本站影响等级。

具体判定规则必须在数据能力完成后单独定义、测试和版本化。在规则尚未验证前，默认输出“暂无法判断”。

### 第四层：属地官方预警

回答“关注城市或所在区县的气象台是否发布了正式预警”。

只有接入可验证的属地官方来源后，才能展示：

- 预警名称和官方图标；
- 预警颜色及等级；
- 发布地区；
- 发布机构；
- 发布时间；
- 更新时间或解除时间；
- 官方原文和防御指南；
- 官方原文链接。

## 官方预警的五种状态

### 1. 存在生效预警

显示完整的预警名称、发布地区、发布机构、发布时间、状态和原文入口。只有这一状态可以使用对应的官方预警颜色。

### 2. 已接入来源，未检索到生效预警

推荐文案：

> 当前已接入来源未检索到厦门生效中的台风预警。

不得简化为“当前安全”。

### 3. 尚未接入属地预警

推荐文案：

> 暂未接入厦门官方预警数据，请前往当地气象部门官方渠道核验。

### 4. 预警数据获取失败

推荐文案：

> 官方预警数据暂时无法获取，当前状态未知。

页面保留最后成功时间和官方核验入口。

### 5. 预警已解除或过期

明确展示解除机构和解除时间。历史预警不继续使用“生效中”的视觉权重和行动提示。

## 页面优先级

正常情况下：

> 数据状态 → 本地影响 → 官方预警状态 → 台风强度

存在生效的属地官方预警时：

> 数据状态 → 属地官方预警 → 立即行动 → 本地影响 → 台风强度

只有真实且生效的属地官方预警可以获得首页最高警示权重。

## 视觉规则

- 蓝、黄、橙、红及官方预警图标仅用于属地官方预警；
- 台风强度使用品牌深青色和文字等级；
- 本地影响采用中性状态词、图标和解释；
- 数据异常使用系统状态样式，不模拟气象预警；
- 所有状态同时使用文字、图标和结构，不只依赖颜色；
- “未检索到”“未接入”“获取失败”“已解除”使用不同的文案和视觉状态。

## 上游 `warnlevel` 字段处理

当前浙江省水利厅路径数据中的 `warnlevel` 统一命名为“来源系统关注标记”。在确认字段定义和适用范围之前，只允许放在数据详情或来源说明中。

该字段不得直接生成或替代：

- 厦门官方台风预警；
- 当前最高预警；
- 属地蓝、黄、橙、红预警；
- 对厦门的风险判断。

## 行动建议

### 官方防御指南

- 与正式预警信息同时展示；
- 保留发布机构、发布时间和官方原文链接；
- 不改变或删减官方结论；
- 官方更新或解除后同步更新状态。

### 本站一般性提示

只使用低风险、非指令性的防灾提示，并明确标注：

> 一般性防灾提示，不是官方指令。

本站提示与官方防御指南必须分区展示，不使用相同标题或卡片样式。

## 数据失效保护

当路径、预警或关键时间字段异常时：

- 停止输出确定性的本地影响结论；
- 将本地影响调整为“当前数据不足，暂无法判断”；
- 保留最后一次成功更新时间；
- 提供属地官方核验入口；
- 不继续沿用旧预警的颜色、有效状态和行动建议；
- 不把“没有获取到预警”解释成“没有风险”。

## 验收标准

- 台风强度、本地影响、官方预警和数据状态不再混用；
- `warnlevel` 不再自动生成厦门官方预警；
- 只有属地气象台发布的信息使用官方预警样式；
- 五种官方预警数据状态可以清晰区分；
- 没有官方预警不被描述为安全；
- 数据过期时停止输出确定性本地影响结论；
- 官方预警显示发布地区、机构、时间、状态和原文入口；
- 本站计算和一般性提示均具有明确身份标识；
- 颜色不是任何风险状态的唯一识别方式。
