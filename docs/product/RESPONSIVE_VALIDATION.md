# 第 13 步：响应式优化与验收

## 优化目标

保证首页、台风详情页和历史对比页在手机、平板及桌面端均可读、可操作，且不发生意外横向滚动。

## 本轮调整

- 新增独立响应式规则层 `dist/responsive.css`，避免改动原有压缩样式；
- 为桌面大屏设置 1296px 内容上限，保持信息聚焦；
- 手机端压缩顶部导航，并保留品牌、城市与返回入口；
- 长中文标题、说明和指标允许安全换行；
- 手机端指标卡改为单列，避免数值与单位被截断；
- 主要按钮、预测时效、官方链接和电话入口最小高度设为 44px；
- 调整地图高度、时间轴栅格和图例换行；
- 详情页数据表增加横向滑动提示、键盘焦点和区域语义；
- 缩减历史对比空状态在小屏上的字号与内边距；
- 分析调试面板在 380px 以下改为纵向标题栏。

## 自动验证方式

运行：

```powershell
node scripts/responsive-check.mjs
```

脚本通过 Edge DevTools Protocol 设置真实页面视口，记录 `clientWidth` 与 `scrollWidth`，并在 `docs/product/responsive/` 生成验证截图。

## 验收结果

| 页面 | 视口 | clientWidth | scrollWidth | 横向溢出 |
| --- | ---: | ---: | ---: | --- |
| 首页 | 360 × 800 | 360 | 360 | 无 |
| 首页 | 390 × 844 | 390 | 390 | 无 |
| 首页 | 768 × 1024 | 753 | 753 | 无 |
| 首页 | 1440 × 1000 | 1425 | 1425 | 无 |
| 台风详情 | 390 × 844 | 390 | 390 | 无 |
| 历史对比 | 390 × 844 | 390 | 390 | 无 |

768px 与 1440px 的页面内容宽度扣除了浏览器垂直滚动条；`scrollWidth` 与 `clientWidth` 一致，因此没有横向溢出。
