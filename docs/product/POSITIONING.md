# 海风哨产品定位

确认日期：2026-10-18  
状态：已确认

## 一句话定位

海风哨是一款面向中国东南沿海居民的台风影响决策助手，将权威台风信息转化为与用户所在城市相关的影响判断和行动建议。

## 用户需要回答的三个问题

1. 这场台风与我有没有关系？
2. 什么时候可能影响我？
3. 我现在应该做什么？

## 目标用户

### 核心用户

- 居住或工作在中国东南沿海城市的普通居民；
- 不熟悉专业气象图，但需要快速安排出行、通勤和家庭防灾准备的人；
- 主要通过手机在台风临近期间查看信息的人。

### 次要用户

- 帮异地家人查看风险的人；
- 前往沿海城市出差或旅行的人。

### 暂不服务

- 气象专业人员；
- 船舶航行、海上作业等专业决策场景；
- 需要专业灾害指挥系统的政府和企业用户。

## 首版验证范围

产品长期定位覆盖中国东南沿海，首版以福建省厦门市作为城市级影响能力的验证样板，再逐步扩展城市。

首版不把静态城市名称包装为真实定位能力。只有当距离、影响时段和本地预警能够由真实数据支持时，才向用户提供对应结论。

## 核心价值主张

| 用户问题 | 产品回答 |
| --- | --- |
| 现在发生了什么 | 当前活动台风、强度、位置和移动方向 |
| 和我有关吗 | 距离所在城市、接近趋势和可能影响窗口 |
| 风险有多大 | 当地官方预警、发布时间和有效状态 |
| 我应该做什么 | 与官方预警对应的简短行动建议 |
| 信息可靠吗 | 权威来源、更新时间、原文入口和延迟状态 |

## 产品优先级

1. 与用户所在位置是否相关；
2. 用户现在应该采取什么行动；
3. 信息是否权威、及时；
4. 台风在哪里、如何移动；
5. 更完整的专业数据。

地图是解释信息的工具，不是产品的最终价值中心。本地影响结论和可执行建议应成为首页核心。

## 对外表达

- 产品名称：海风哨；
- 产品类型：台风影响决策助手；
- 推荐副标题：台风离你多远，何时影响，现在该做什么；
- 首页价值说明：结合权威台风数据和用户选择的城市，快速说明影响、时间与行动建议。

## 安全边界

- 不自行发布或生成官方预警；
- 不根据路径预测自行判定行政区域预警级别；
- 明确区分台风实况、预测路径、本地官方预警和本站解释；
- 关键数据必须展示来源和更新时间；
- 数据延迟、加载失败和字段缺失时必须明确告知用户；
- 行动建议以官方防御指南为依据，并保留官方原文入口；
- 精确定位必须获得用户授权，默认不长期保存；
- 不为海上作业等专业高风险决策提供结论。

## 成功标准

- 用户能用一句话准确复述产品用途；
- 用户在首屏 10 秒内判断当前台风与所选城市是否相关；
- 用户在 30 秒内找到预计影响时间和下一步行动；
- 用户能够识别实况、预测、官方预警和本站解释的区别；
- 城市级结论可以追溯到真实数据，不使用演示内容冒充真实能力。

## 作品集证明目标

该定位用于证明产品设计者能够：

- 从数据展示转向用户决策；
- 为高风险信息建立清晰的信息层级；
- 设计实时数据的来源、时效、异常和回退机制；
- 处理定位、个性化、安全边界和产品责任；
- 通过指标和用户测试验证产品是否真正帮助用户决策。
