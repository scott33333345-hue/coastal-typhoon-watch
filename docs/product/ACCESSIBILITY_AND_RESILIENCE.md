# 第 14 步：无障碍与极端环境优化

## 目标

让键盘用户、读屏用户、需要减少动画或更高对比度的用户都能完成核心任务，并保证地图、网络、本地存储或 JavaScript 不可用时仍有可信的安全出口。

## 无障碍改造

- 首页、详情页和历史对比页均提供“跳到主要内容”链接；
- 所有可见交互控件具有可读名称和高辨识度焦点环；
- 预测时效按钮通过 `aria-pressed` 表达当前选择；
- 城市弹窗使用原生 `dialog`，打开后聚焦关闭按钮，关闭后返回触发按钮，并同步 `aria-expanded`；
- 地图改为带说明的区域，提供“跳过交互地图，查看文字路径”入口；
- 厦门参考点和台风当前位置标记具有可读标题；
- 图表的读屏名称会包含时间范围、最低值和最高值；
- 详情数据表具有可聚焦的滚动区域和明确标签；
- 支持系统减少动画、更高对比度和强制颜色模式；
- 主要操作目标保持至少 44px 高。

## 极端环境回退

- Leaflet脚本不可用：隐藏交互地图并展示文字时间线提示；
- 地图瓦片不可用：保留路径数据，同时显示底图不可用提示；
- 数据加载失败：保持官方来源和紧急电话可访问；
- 本地存储被禁止：关注和提醒不会误报成功，并明确说明未保存；
- JavaScript关闭：首页与详情页显示说明和官方核验链接；
- 减少动画开启：取消平滑滚动和非必要动画；
- 打印或截图：隐藏地图控件、关注和分享操作，保留文字路径及来源；
- 200%缩放：页面保持无横向溢出。

## 产品边界

本轮提高了前端页面的可访问性与韧性，但不宣称通过任何第三方无障碍认证。正式上线前仍应邀请真实的键盘和读屏用户完成任务测试。
