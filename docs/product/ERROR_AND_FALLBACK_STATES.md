# 海风哨异常与回退状态设计

确认日期：2026-10-18  
状态：已确认

## 核心原则

宁可明确显示“暂时无法判断”，也不能让占位内容、旧预警或不完整数据看起来仍然有效。

异常处理采用“分模块降级、最后有效数据回退、旧数据停止驱动实时结论”的方案。

## 1. 全局状态

| 状态 | 页面处理 |
| --- | --- |
| 初次加载 | 展示骨架结构，不显示虚构数值或默认预警 |
| 数据正常 | 展示完整内容、来源和实际时间 |
| 上游无变化 | 正常展示，说明最近检查成功 |
| 部分数据缺失 | 保留有效模块，缺失模块独立降级 |
| 来源实况延迟 | 展示来源时间和延迟提示，降低结论确定性 |
| 抓取失败且有历史数据 | 展示最后有效数据并标记缓存状态 |
| 抓取失败且无历史数据 | 进入安全错误页，只保留官方入口和重试 |
| 数据结构异常 | 拒绝渲染异常数据 |
| 当前无活动台风 | 展示正常的无活动台风状态 |
| 用户网络离线 | 展示离线状态和最后有效内容 |

## 2. 分模块状态

以下模块分别维护状态，单个模块失败不得导致整页不可用：

- 台风实况；
- 预测路径；
- 属地官方预警；
- 城市位置；
- 个性化空间计算；
- 地图底图；
- 数据更新时间和采集健康度。

页面需要能够同时表达“实况正常、预测缺失、属地预警尚未接入、底图失败但文字路径可用”等组合状态。

## 3. 初次加载

- 使用与最终模块结构一致的简洁骨架；
- 不提前显示黄色、红色等预警卡；
- 不使用默认台风名称、强度或城市风险；
- 不用数字 0 代替尚未获取的数据；
- 加载时间较长时显示文字提示；
- 提供重新加载和官方渠道入口；
- 数据到达后完整替换骨架，避免两种状态并存。

## 4. 字段缺失

### 非关键字段

英文名称、气压、风圈等非关键字段缺失时：

- 其他有效数据继续展示；
- 缺失位置显示“来源暂未提供”；
- 不使用 0、空字符串或模拟值填充。

### 关键字段

坐标、实况时间、预测机构等关键字段缺失时：

- 停止依赖该字段的距离、趋势或预测计算；
- 显示“当前数据不足，暂无法判断”；
- 不影响无依赖关系的有效模块。

### 多个关键字段异常

- 将对应台风标记为数据不完整；
- 不用于首页默认个性化结论；
- 保留来源、最后有效时间和问题说明。

## 5. 延迟状态

分别判断：

- 自动任务最近成功检查时间；
- 来源最新实况时间；
- 当前页面发布时间；
- 属地官方预警最新同步时间。

来源实况超过允许时间时：

- 仍可展示最后实况；
- 明确显示最后实况距今时间；
- 本地影响结论调整为“暂无法确认最新影响”；
- 预测路径显示其机构和发布时间；
- 停止显示“正在影响”等实时性结论。

不同来源采用独立、可配置的时效阈值，不使用单一的 45 分钟规则判断全部数据。

## 6. 最后有效数据

抓取失败但存在通过 Schema 和业务校验的数据时：

- 展示最后有效数据；
- 显示缓存标识和数据时间；
- 显示本次失败时间；
- 保留官方来源链接；
- 提供手动重试；
- 隐藏依赖最新实况的接近趋势和影响结论；
- 不继续将缓存中的官方预警表现为实时生效；
- 不使用旧数据驱动实时行动建议。

推荐文案：

> 当前数据获取失败，以下为最近一次通过校验的数据，仅供参考。

## 7. 无可用数据

没有任何有效数据或缓存时：

- 不展示空地图、空指标卡和永久载入状态；
- 不显示默认预警颜色；
- 明确说明当前无法获取台风数据；
- 提供重新加载按钮；
- 提供路径来源和厦门属地官方渠道；
- 显示错误时间和可用于排查的非敏感故障编号。

推荐文案：

> 当前无法获取台风数据，请直接查看官方渠道。本站不会根据缺失数据判断风险。

## 8. 无活动台风

无活动台风属于正常业务状态，不是错误：

- 显示来源当前未列出活动台风；
- 显示最近成功检查时间；
- 可以进入最近历史台风；
- 保留关注城市设置和手动刷新；
- 历史台风标记为“已停止编号／历史回顾”；
- 移除活动状态、实时预警样式和实时行动建议。

## 9. 属地官方预警异常

官方预警模块独立支持：

- 尚未接入；
- 已接入且未检索到生效预警；
- 获取失败，状态未知；
- 数据延迟；
- 已经解除；
- 字段不完整，需要核对原文。

任何异常或缺失状态均不得转换为“无预警”或“当前安全”。

## 10. 地图与路径异常

- 底图失败时保留路径摘要、文字时间线和来源；
- 路径失败时保留最新有效台风实况；
- 单个坐标异常时忽略该点并记录说明；
- 地图脚本失败时不影响预警和行动模块；
- 移动设备性能不足时允许切换纯文字路径；
- 无预测路径时明确说明来源暂未提供预测。

## 11. 离线状态

用户曾成功访问网站后，可以缓存：

- 基本页面结构；
- 最后一份通过校验的台风数据；
- 数据版本和缓存时间；
- 官方渠道链接。

离线时：

- 显示“当前离线”；
- 显示缓存数据时间；
- 不显示“数据已同步”；
- 禁用必须联网的刷新和定位增强功能；
- 网络恢复后提示重新获取最新数据。

## 12. 恢复与重试

- 提供手动重试；
- 自动重试次数有限；
- 自动重试采用递增间隔；
- 重试期间保留有效旧内容；
- 恢复后刷新状态并以非打断方式通知；
- 不循环弹出错误提示；
- 用户正在阅读或操作时不重置焦点。

## 13. 状态通知与无障碍

- 动态状态区域使用合适的 `aria-live`；
- 普通数据刷新使用非打断通知；
- 加载失败和重要官方预警变化提供明确通知；
- 状态变化不导致焦点突然跳转；
- 错误和警告同时使用文字、结构和图标，不只依赖颜色；
- 重试按钮、官方链接和文字回退支持键盘操作。

## 14. 测试矩阵

至少为以下场景准备固定测试样本：

- 正常数据；
- 空台风列表；
- 两个活动台风；
- JSON 无法解析；
- Schema 版本不支持；
- 坐标缺失或越界；
- 实况时间无效或倒序；
- 预测路径缺失；
- 预测机构缺失；
- 来源实况超过允许时间；
- 自动任务抓取失败；
- 存在最后有效数据；
- 不存在任何有效数据；
- 本地预警接口失败；
- 底图加载失败；
- 浏览器离线；
- 缓存 Schema 版本过旧；
- 网络恢复。

## 验收标准

- 页面不存在永久“载入中”；
- 失败时不显示虚构、默认或残留数据；
- 单个模块失败不会导致整页不可用；
- 旧数据具有醒目的时间和缓存标识；
- 旧官方预警不继续表现为实时生效；
- 数据过期时停止个性化实时结论；
- 无活动台风与加载失败明确区分；
- 无有效数据时提供官方核验出口；
- 地图失败后文字时间线仍然可用；
- 离线状态不显示数据已同步；
- 所有关键异常场景都有测试样本和预期输出。
