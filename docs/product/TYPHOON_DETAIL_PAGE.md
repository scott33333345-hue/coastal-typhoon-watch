# 海风哨台风详情页设计

确认日期：2026-10-18  
状态：已确认

## 页面定位

首页用于帮助用户快速判断，详情页用于帮助用户完整理解一场台风的生命周期、强度变化、路径预测和数据依据。

详情页不重复堆叠首页内容，也不根据台风强度自行生成属地预警或行动指令。

## 1. 页面入口与地址

首版采用适配 GitHub Pages 的独立页面和查询参数：

```text
/typhoon.html?id=202630
```

入口包括：

- 首页当前台风摘要；
- 路径地图中的台风切换；
- 历史台风列表；
- 可复制分享链接。

异常状态：

- 缺少 `id` 时引导返回当前台风；
- 编号不存在时显示未找到状态；
- 数据加载失败时保留官方来源和重试；
- Schema 版本不兼容时停止渲染；
- 链接中不包含用户精确位置。

## 2. 页面信息架构

详情页采用：

> 可信状态 → 台风身份 → 当前实况 → 本地关联 → 路径预测 → 生命周期 → 强度趋势 → 专业数据 → 来源说明

## 3. 可信状态

页面顶部显示：

- 数据健康状态；
- 来源最新实况时间；
- 最近成功检查时间；
- 页面发布时间；
- 当前是否使用缓存数据；
- 官方来源入口。

缓存或延迟状态必须降低依赖最新数据的结论确定性。

## 4. 台风身份

展示：

- 中文名和英文名；
- 国际编号或国内编号；
- 活动中或已停止编号；
- 生成时间；
- 最后有效实况时间；
- 数据来源。

活动台风和历史台风使用不同状态表达，停编台风不得显示为正在活动。

## 5. 当前实况

核心指标包括：

- 台风强度；
- 中心经纬度；
- 最大风力和风速；
- 中心气压；
- 移动方向与速度；
- 七、十、十二级风圈。

指标提供简短解释。台风中心强度不得被描述为某座城市的实际影响或官方预警。

## 6. 本地关联

沿用用户当前选择的城市，展示：

- 当前距离；
- 相对方向；
- 接近或远离趋势；
- 预测路径最近点；
- 属地官方预警数据状态。

同时标明：

- 本站坐标计算；
- 使用的实况时间；
- 使用的预测机构；
- 城市参考点或设备位置；
- 结果不代表登陆或官方影响判断。

未选择城市时显示选城入口，不阻止查看详情页其他内容。

## 7. 路径与预测

详情页地图支持：

- 完整历史实况路径；
- 当前台风中心；
- 按机构分组的预测路径；
- 未来 24、48、72、120 小时范围；
- 七、十、十二级风圈开关；
- 关注城市标记；
- 路径节点详情；
- 等价的文字时间线。

默认展示中国预测机构。其他机构可以切换，但不同机构的点不得连接为同一条预测路径。只有一个机构时不显示无意义的切换器。

页面明确提示预测会随新资料调整，不将预测点描述为一定到达的位置。

## 8. 生命周期时间线

根据来源数据按时间生成关键事件：

- 台风生成；
- 升级为热带风暴；
- 升级为台风；
- 达到强台风或超强台风；
- 达到本次最大强度；
- 权威来源明确记录的登陆事件；
- 减弱；
- 停止编号。

关键事件只能来自字段变化或权威记录。不得根据相邻坐标自行推断登陆事件。普通实况点默认折叠，可展开查看完整列表。

## 9. 强度趋势

### 风速变化

- 横轴为时间；
- 纵轴为最大风速；
- 标记关键强度变化；
- 突出当前或最终有效点。

### 中心气压变化

- 横轴为时间；
- 纵轴为中心气压；
- 明确单位为百帕；
- 不把单一气压变化解释成属地安全结论。

可以后续增加移动速度、风力等级和城市距离趋势。每张图表必须具有数据表或文字摘要替代。

## 10. 专业数据

专业数据默认折叠，包括：

- 七级风圈四象限；
- 十级风圈四象限；
- 十二级风圈四象限；
- 完整实况节点；
- 完整预测节点；
- 原始字段解释；
- 字段缺失和数据质量说明。

原始风圈字符串需要转换为东北、东南、西南、西北象限，不直接向普通用户展示 `350|280|320|250` 等编码。

## 11. 属地官方预警

根据当前关注城市展示：

- 发布机构；
- 发布地区；
- 预警名称和等级；
- 发布时间；
- 生效、更新或解除状态；
- 官方原文；
- 官方防御指南。

尚未接入属地官方预警时显示能力缺失，不使用路径来源的 `sourceAttentionMark` 替代。

## 12. 活动与历史状态

### 活动台风

- 默认展示最新实况和预测；
- 允许自动刷新；
- 刷新不打断用户阅读和焦点；
- 数据变化时以非打断方式提示。

### 已停止编号台风

- 标记为历史回顾；
- 停止自动刷新；
- 不展示实时行动建议；
- 预测路径隐藏或明确标注为历史预测；
- 显示最后有效实况时间。

## 13. 分享

默认分享内容包含：

- 台风名称；
- 最新实况时间；
- 详情页链接；
- 数据来源提示。

不得自动加入：

- 用户精确位置；
- 未验证的本地风险结论；
- 已经过期的官方预警；
- “即将登陆”等确定性描述。

## 14. 移动端

移动端顺序：

1. 名称和状态；
2. 当前实况；
3. 与关注城市的关系；
4. 路径地图；
5. 文字时间线；
6. 强度趋势；
7. 官方预警；
8. 专业数据和来源。

要求：

- 指标使用两列或单列布局；
- 图表内部可进行时间浏览，但页面本身不横向溢出；
- 地图默认高度约 400px；
- 专业数据默认折叠；
- 分享和返回首页入口易于到达。

## 15. 数据文件拆分

当完整台风数据影响首页加载时，拆分为：

```text
data/index.json
data/typhoons/202630.json
```

`index.json` 只包含首页和台风选择所需摘要。详情页根据编号加载单场完整路径、机构预测、风圈和趋势数据。

## 验收标准

- 每场台风具有稳定、可复制的详情页链接；
- 活动台风和历史台风明确区分；
- 首页与详情页职责清晰；
- 路径按照预测机构分组；
- 生命周期事件来自真实字段变化或权威记录；
- 风速和气压趋势具有文字或表格替代；
- 风圈数据转换为用户可理解的象限；
- 属地官方预警与台风强度保持分离；
- 停编台风不显示实时行动建议；
- 分享链接不包含精确位置；
- 缺失编号、数据失败和历史数据都有完整状态；
- 390px 移动端不存在页面级横向滚动。
